# StarryNight / Repair New Version

Una versión completamente reparada y optimizada del popular tema StarryNight para las versiones modernas de Spotify en Windows, macOS y Linux.

## Mejoras y Reparaciones (Changelog)
- **Disco de Vinilo Giratorio Adaptativo**: Altura y padding corregidos para evitar que la portada circular y su resplandor queden cortados.
- **Contracción Inteligente del Panel**: Al ocultar la vista de "Estás escuchando", el reproductor superior también se contrae y se oculta automáticamente, permitiendo que la ventana principal ocupe todo el ancho.
- **Lluvia de Estrellas Clásica Restaurada**: Animación original de meteoros de Delroy Prithvi con parpadeo suave por keyframes y duraciones dinámicas sin bloqueos.
- **Botones 100% Visibles**: Iconos y botones del reproductor y panel lateral con opacidad y color nítidos para máxima visibilidad sobre el fondo estrellado.
- **Compatibilidad con Letras (Lyrics)**: Compatible con las letras nativas y plugins de karaoke de terceros (como Spicy Lyrics / Beautiful Lyrics / Lyrics Plus) sin romper sus degradados ni animaciones letra por letra.

## Créditos
- Tema original: Brandon Chen y Julissa Laignelet.
- Animación de estrellas fugaces: Delroy Prithvi (Pure CSS Shooting Star Animation Effect).
